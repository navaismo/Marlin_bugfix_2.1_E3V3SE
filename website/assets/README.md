# Website assets

- `skin-octoprint-collage.jpg` and `skin-eva-collage.jpg`: collages made from real LCD theme photographs. Both are shared by the website's light and dark themes and can be enlarged on the page.
- `octoprint-thumbnail.jpg`: photograph used in the Host Only thumbnail example.
- `octoprint-settings.png`: supplied LCD E3V3SE plugin settings screenshot, copied from `OctoPrint-LCD_E3V3SE/dist/screens/settings.png`.
- `cacomixtlepad-logo.png`: original CacomixtlePad app logo from [splash5_padded.png](https://github.com/navaismo/cacomixtlePad/blob/main/assets/icons/splash5_padded.png), shared by all variants and themes.
- `ender3-v3se-hero.png`: transparent printer and blue pedestal used in the page hero.
- `cacomixtlepad-interfacee.gif`: CacomixtlePad interface demo; the page shows a placeholder if it cannot be loaded.
